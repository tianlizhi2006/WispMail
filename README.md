# WispMail

> 一缕轻风般的桌面邮件客户端 —— 轻巧、快速，接入你所有的邮箱。

WispMail 是一款面向 PC 的轻量级邮件客户端。它的目标是在保持小巧、启动迅速、占用资源低的同时，提供一个邮件客户端应有的完整日常功能，并能同时接入主流邮件服务商与私有 / 企业自建邮箱。

> 🚧 项目处于早期设想与规划阶段，欢迎关注。

---

## 设计目标

- **轻量**：安装包小、启动快、内存占用低，常驻后台也不拖慢电脑。
- **通用**：一个客户端管理所有邮箱，无论是大厂邮箱还是自建邮件服务器。
- **够用**：覆盖日常收发、整理、搜索邮件的全部必要功能，不堆砌冷门特性。
- **安全与隐私**：凭据安全保存，邮件内容安全展示，默认防范邮件追踪。

---

## 支持的邮箱

| 类型 | 示例 | 说明 |
|---|---|---|
| 国际主流邮箱 | Gmail、Outlook.com / Microsoft 365、iCloud、Yahoo | 支持官方授权登录（无需交出邮箱密码） |
| 国内主流邮箱 | QQ 邮箱、网易 163 / 126、阿里邮箱、新浪邮箱 | 支持授权码 / 应用专用密码登录 |
| 私有 / 企业邮箱 | 公司自建邮件服务器、个人域名邮箱 | 手动填写收发信服务器地址、端口与加密方式 |

- 支持 **IMAP**、**POP3** 收信与 **SMTP** 发信。
- 输入邮箱地址后**自动识别服务器配置**，大多数情况下无需手动填写。

## 功能规划

### 第一阶段：核心可用（MVP）

**账户**
- [ ] 添加、编辑、删除多个邮箱账户
- [ ] 自动识别常见邮箱的服务器配置
- [ ] 官方授权登录（Gmail、Outlook 等）与密码 / 授权码登录
- [ ] 账户凭据安全存储于系统凭据管理器

**收信与阅读**
- [ ] 邮件同步，新邮件实时到达
- [ ] 统一收件箱：所有账户的邮件集中查看
- [ ] 本地缓存，离线也可阅读已同步邮件
- [ ] 安全显示 HTML 邮件，屏蔽恶意脚本
- [ ] 默认拦截远程图片，防止邮件追踪，可按需加载
- [ ] 查看、预览与保存附件

**整理**
- [ ] 文件夹浏览与管理（新建、重命名、删除）
- [ ] 标记已读 / 未读、星标、删除、移动、归档
- [ ] 批量操作

**撰写与发送**
- [ ] 新建、回复、全部回复、转发
- [ ] 富文本编辑与纯文本模式
- [ ] 添加附件（支持拖拽）
- [ ] 草稿自动保存
- [ ] 每个账户独立签名
- [ ] 联系人地址自动补全

**搜索**
- [ ] 本地全文搜索（发件人、主题、正文）
- [ ] 按账户、文件夹、时间、是否有附件等条件筛选

**桌面体验**
- [ ] 新邮件系统通知
- [ ] 最小化到系统托盘、开机自启
- [ ] 浅色 / 深色主题
- [ ] 常用操作键盘快捷键

### 第二阶段：增强体验

- [ ] 会话视图（按话题聚合往来邮件）
- [ ] 邮件过滤规则（自动分类、标记、移动）
- [ ] 稍后提醒 / 定时发送
- [ ] 本地通讯录管理
- [ ] 邮件导入 / 导出（.eml）
- [ ] 多语言界面（中文 / English）

### 第三阶段：进阶功能

- [ ] 邮件加密与签名（PGP、S/MIME）
- [ ] Exchange 企业邮箱支持
- [ ] 日历邀请的查看与回复
- [ ] macOS / Linux 版本

## 不做什么

为了保持轻量，WispMail **不会**内置以下内容：

- 广告、资讯推送或任何与邮件无关的功能
- 强制云端账号或把你的邮件上传到第三方服务器
- 臃肿的办公套件式集成

你的邮件只在你的电脑与你的邮件服务商之间传输。
