# WispMail

> 一缕轻风般的桌面邮件客户端 —— 轻巧、快速，接入你所有的邮箱。

WispMail 是一款面向 PC 的轻量级邮件客户端。它的目标是在保持小巧、启动迅速、占用资源低的同时，提供一个邮件客户端应有的完整日常功能，并能同时接入主流邮件服务商与私有 / 企业自建邮箱。

> 🚧 项目处于早期开发阶段，开发顺序与进度见 [路线图](docs/ROADMAP.md)。

当前版本已实现自建 / 域名邮箱的核心收发：文件夹浏览、分页同步、安全阅读 HTML / 纯文本、已读标记、星标 / 归档 / 移动 / 删除及多选批量操作、附件保存、新建 / 回复 / 全部回复 / 转发、抄送 / 密送、附件发送、本地草稿、新邮件实时到达与系统通知、本地全文搜索，以及托盘常驻与开机自启。支持独立收发信用户名和密码、TLS / STARTTLS，凭据交给系统凭据管理器，已下载邮件缓存在 SQLite 中。POP3、OAuth2 和高级整理仍在开发计划中；下方清单包含规划能力。真实服务器验收步骤见 [自建邮箱指南](docs/SELF_HOSTED.md)。

## 设计目标

- **轻量**：安装包小、启动快、内存占用低，常驻后台也不拖慢电脑。
- **通用**：一个客户端管理所有邮箱，无论是大厂邮箱还是自建邮件服务器。
- **够用**：覆盖日常收发、整理、搜索邮件的全部必要功能，不堆砌冷门特性。
- **安全与隐私**：凭据安全保存，邮件活动内容隔离过滤，提供远程图片加载控制。

## 支持的邮箱

| 类型 | 示例 | 说明 |
|---|---|---|
| 国际主流邮箱 | Gmail、Outlook.com / Microsoft 365、iCloud、Yahoo | 应用专用密码取决于账户策略；Gmail / Outlook 官方授权登录待实现 |
| 国内主流邮箱 | QQ 邮箱、网易 163 / 126、阿里邮箱、新浪邮箱 | 支持授权码 / 应用专用密码登录 |
| 私有 / 企业邮箱 | 公司自建邮件服务器、个人域名邮箱 | 手动填写收发信服务器地址、端口与加密方式 |

- 当前支持 **IMAP** 收信与 **SMTP** 发信，**POP3** 待实现。
- 输入邮箱地址后**自动识别服务器配置**，大多数情况下无需手动填写。

## 不做什么

为了保持轻量，WispMail **不会**内置以下内容：

- 广告、资讯推送或任何与邮件无关的功能
- 强制云端账号或把你的邮件上传到第三方服务器
- 臃肿的办公套件式集成

你的邮件只在你的电脑与你的邮件服务商之间传输。

### 本地开发

需要 Node.js（LTS）与 Rust（stable）；Windows 还需要 Visual Studio C++ 生成工具。

```bash
npm install          # 安装前端依赖
npm run tauri dev    # 启动开发版
npm run tauri build  # 打包安装程序
```

仅运行 `npm run dev` 可预览界面；账户配置、连接测试和保存需要在 `npm run tauri dev` 启动的桌面窗口中使用。账户配置保存在应用数据目录的 `wispmail.sqlite3` 中，密码 / 授权码不会写入数据库或浏览器存储。

开发检查与账户验收步骤见 [开发与验证指南](docs/DEVELOPMENT.md)。

自建服务器的连接步骤和配置示例见 [自建 / 域名邮箱接入](docs/SELF_HOSTED.md)。
